`main.py` (Python 3, standard library only) writes one original roast — 122 characters, a single line — to `/output/entry.txt`:

> I asked my agent for one line; it wrote a plan, a roadmap and a retrospective, then asked whether I still wanted the line.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
